# 🧑‍🏫 Top Courses Project

This is a responsive React-based project that displays a list of top courses with filtering functionality and a like system using icons and toast notifications.

---

## 📌 Features

- ✅ Displays popular courses with title, image, and description
- ✅ Allows filtering courses by category
- ✅ Like/Unlike functionality with icon toggle (`FcLike`, `FcLikePlaceholder`)
- ✅ Toast notifications using `react-toastify`
- ✅ Responsive UI styled with Tailwind CSS

---

## 🧪 Technologies Used

- React JS
- Tailwind CSS
- React Icons
- React Toastify
